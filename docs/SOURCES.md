# Fontes e proveniência

## Fonte primária

- Nome: Day R Wiki
- Host: `dayr.wiki.gg`
- Idioma: inglês
- API: `https://dayr.wiki.gg/api.php`
- Prioridade inicial: 1

A fonte foi escolhida inicialmente por oferecer MediaWiki API, categorias de itens, revisões recentes e catálogo ativo de arquivos. A decisão não é permanente.

## Avaliação de fontes

Uma fonte alternativa só deve assumir prioridade depois de um conjunto de evidências: mudanças recentes consistentes, páginas alinhadas a versões atuais, boa cobertura de itens, arquivos ativos e manutenção de eventos. Blogs, lojas, fóruns aleatórios, mecanismos de busca e agregadores de SEO não são fontes principais aceitáveis.

## Conflitos

Não combine valores diferentes silenciosamente. Prefira, nesta ordem:

1. página explicitamente marcada para a versão mais recente;
2. revisão mais recente com conteúdo pertinente;
3. fonte com atividade recente consistente;
4. fonte primária configurada.

Se a evidência não resolver o conflito, exiba “Informação requer verificação”.

## Licenças e atribuição

O sincronizador preserva os metadados de licença e atribuição expostos pela MediaWiki para cada arquivo. Nem todos os arquivos necessariamente usam a mesma licença. A página de origem do arquivo é a referência final; não remova créditos ou avisos existentes.
